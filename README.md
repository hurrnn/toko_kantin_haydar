# Kantin Kita

Aplikasi katalog menu kantin sekolah berbasis Flutter. Siswa dapat mencari
menu, melihat detail dan harga, mengatur porsi, serta meninjau keranjang
belanja dan informasi operasional kantin.

## Menjalankan aplikasi

```bash
flutter pub get
flutter run
```

## Membangun APK Android

```bash
flutter build apk
```

Daftar menu dan gambar ilustrasi lokal berada di `lib/data/menu_data.dart` dan
`assets/images/`.
